# ⚔️ 矿洞地牢 (Dungeon Crawler)

**一款基于 HTML5 Canvas 和纯 JavaScript 开发的 Web 端像素风 Roguelite 地牢冒险游戏。**

---

## 📖 游戏简介

**《矿洞地牢 修复版》** 是一款无需安装、即开即玩的网页游戏。玩家将扮演冒险者深入随机生成的矿井地牢，击败各路怪物，收集金币与战利品，购买强力武器和个性化时装，并寻找通往下一层的金色楼梯。

游戏内置了基于 Firebase 的**双人在线合作模式**，支持跨设备联机，且自动适配 PC 与移动端的操作方式。

---

## ✨ 核心特性

* **🎮 多模式游玩**：支持经典的单人闯关模式，以及基于 Firebase 实时数据库的“双人合作”模式（支持快速匹配与房间号邀请）。
* **🗺️ 随机生成地牢**：内置 A* 寻路算法与程序化地图生成。随着层数深入，地图会从“古堡”演变为“迷宫”、“十字殿”、“螺旋”、“洞窟”及“竞技场”等多种地形。
* **⚔️ 丰富的装备与成长系统**：
* **武器**：数十种近战/远程武器（如巨魔战斧、冰霜法杖、圣剑等），附带穿透、燃烧、中毒、减速等特殊弹道效果。
* **外观**：自定义性别，并提供多种防具、帽子、披风、特效光环（如暗影缠绕、神圣之光）和面部配饰。
* **升级**：打怪获取经验升级，提升基础攻击力与血量上限。


* **👾 阶梯式敌人设计**：包含史莱姆、蝙蝠、骷髅、哥布林、蜘蛛、巨石怪等多种怪物，每 5 层将遭遇强大的守关 Boss。
* **💾 云端与本地双存档**：自动保存进度（金币、装备、等级）至浏览器 LocalStorage，并在联机模式下同步至 Firebase 云端。
* **📱 全平台适配**：自动识别设备类型。PC 端使用键盘操作，移动端自动呼出高灵敏度的虚拟摇杆与攻击按钮。

## 🕹️ 操作指南

游戏会自动检测您的设备并切换对应的控制模式：

| 平台 | 移动 | 攻击 | 快捷键/其他 |
| --- | --- | --- | --- |
| **PC 端** | `W` `A` `S` `D` 或 方向键 | `Space` (空格键) | UI 界面直接鼠标点击 |
| **移动端** | 左侧屏幕滑动 (虚拟摇杆) | 右下角攻击按钮 | 底部快捷栏点击使用道具 |

## 🛠️ 部署与运行

本项目为纯前端静态文件，没有任何复杂的构建步骤。

**单机模式体验：**

1. 下载源码。
2. 直接在现代浏览器中双击打开 `index.html` 或 `k.html` 即可游玩单机模式。

**联机模式（多人合作）部署：**
多人联机功能依赖 Firebase Realtime Database。

1. 在 [Firebase 控制台](https://console.firebase.google.com/) 创建一个 Web 项目。
2. 启用 **Authentication** (匿名登录) 和 **Realtime Database**。
3. 如果您有自己的 Firebase 配置，请在 `k.html` 中替换 `__firebase_config` 变量的值；否则代码将尝试使用默认提供的演示数据库。
4. 将文件部署到任何静态服务器（如 GitHub Pages, Vercel, Netlify 或本地 Nginx Server），即可解锁完整的“双人合作”功能。
