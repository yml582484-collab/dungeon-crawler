# ⚔️ 矿洞地牢 (Dungeon Crawler)

> 一款基于纯前端 Canvas 实现的像素风格地牢探索游戏，支持手机/电脑双端游玩，支持双人联机协作模式。

---

## 🎮 游戏特色

- **📱 全平台适配** — 手机端触屏操作（虚拟摇杆+攻击按钮），电脑端键盘操控
- **👥 双人联机** — 支持实时多人合作闯关
- **⚔️ 丰富武器系统** — 剑、火剑、雷电、冰霜、暗影、圣光、斧、弓等近战远程武器
- **🎭 角色装扮** — 多套皮肤、披风（含天使羽翼/恶魔之翼）、配饰、帽子、特效
- **🗺️ 随机地图** — 6种地图类型：古堡、迷宫、十字殿、螺旋、洞窟、竞技场
- **💊 道具系统** — 血药、大血药、爆裂炸弹、速度药水、力量药水、护盾
- **🏪 商店系统** — 购买武器装备和时装
- **💾 本地存档** — 自动保存进度

## 🕹️ 操作方式

### 电脑端
| 按键 | 功能 |
|------|------|
| `W/A/S/D` 或 `方向键` | 移动 |
| `空格` / `J` / `K` | 攻击 |
| `E` | 打开背包 |
| `R` | 打开商店 |

### 手机端
- **左侧虚拟摇杆** — 控制移动方向
- **右侧攻击按钮** — 发动攻击
- **顶部按钮** — 背包 / 商店 / 设置

## 🛠️ 技术栈

- 纯 **HTML5 + CSS3 + JavaScript**，无需构建工具
- **Canvas 2D API** 渲染游戏画面
- **Web Audio API** 生成音效
- **localStorage** 本地数据持久化
- 单文件架构 (`k.html`)，开箱即用

## 🚀 快速开始

```bash
# 方式1: 直接打开
open k.html

# 方式2: 本地服务器
npx http-server -p 8080
# 访问 http://localhost:8080/k.html
```

## 🎯 游戏元素

### 武器类型
| 类型 | 代表武器 | 特点 |
|------|---------|------|
| 近战 | 锈剑→骑士剑→炎剑等 | 高伤害，近身作战 |
| 远程 | 弓箭→火球杖→暗影法杖 | 安全距离输出 |
| 特殊 | 圣光锤→雷霆战斧 | 范围伤害/穿透效果 |

### 地图类型
- 🏰 **古堡** — 经典房间式布局
- 🌀 **迷宫** — 复杂通道结构
- ✝ **十字殿** — 对称十字形
- 🐚 **螺旋** — 盘旋上升路径
- 🕳️ **洞窟** — 不规则天然洞穴
- ⚔ **竞技场** — 开阔战斗空间

### 时装系统
- 👤 **皮肤**: 默认、暗影、忍者、法师、龙裔
- 🧥 **披风**: 红/蓝/火焰/暗影/彩虹/天使羽翼/恶魔之翼
- 👒 **帽子**: 无、恶魔角
- 💍 **配饰**: 眼镜、面具、眼罩、蝴蝶结、骷髅项链、魔法戒指
- ✨ **特效**: 无、火焰光环

## 📱 移动端优化

- 虚拟摇杆 + 攻击按钮
